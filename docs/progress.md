# Прогресс мини-игр «как в гонке»

В гонке у ребёнка есть трассы со звёздами, «своя трасса» и гараж: заезд без ошибок даёт следующую машину.
Остальные игры получили то же через общий модуль:

- `src/core/progress.ts` — чистая логика и хранилище (`localStorage` ключ `yunga-progress`, по игре: лучшие звёзды на каждом уровне, полученные предметы, выбранный предмет, сколько игр и сколько на три звезды, самый высокий уровень).
- `src/games/common/collections.ts` — коллекции игр. Почти везде это наклейки со словами (картинки и английские клипы общие со змейкой), у змейки Шуши — шкурки, которые надеваются в игре.
- `src/games/common/progressUi.ts` — полоска на экране итогов (лесенка уровней со звёздами и кнопка «Коллекция»), экран коллекции и выдача нового предмета.

Правило: игра на ★★★ — следующий предмет коллекции, как машина за заезд без ошибок. Следующий предмет виден силуэтом с подписью «следующая», полученный по нажатию называется по-английски.

## Как подключить новую игру

1. Добавить коллекцию в `COLLECTIONS` и число уровней в `LEVELS` (`collections.ts`).
2. На экране итогов, после своих кнопок, вызвать
   `showProgress(this, { game: 'id', level: уровеньИгры, stars, next: уровеньНаСледующуюИгру })`.
   Если экран итогов закрывается без перезапуска сцены, положить `.bar` из результата в свой слой.
3. Новые английские реплики — в `content/phrases.json` (`english.words`), их озвучит GitHub Action.
