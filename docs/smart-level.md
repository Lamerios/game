# Умное усложнение уровней

Общий модуль `src/core/smartLevel.ts`. Решает уровень на следующую игру по итогам
этой игры и нескольких прошлых. Память — `localStorage['yunga-smart-level']`,
по последним 8 играм каждой игры (уровень, точность, медиана времени ответа, сдвиг).

## Правило

| Что было в игре | Сдвиг | `levelReason` |
|---|---|---|
| Всё верно **и** (быстро **или** прошлая игра тоже подняла уровень **или** серия ≥ 8 первых попыток) | **+2** | `skip` |
| Точность ≥ порога подъёма (по умолчанию 90 %) | +1 | `up` |
| Точность ≥ порога, но не идеально и очень медленно | 0 | `steady` |
| Две «шаткие» игры подряд на одном уровне (< 75 %) | −1 | `shaky` |
| Точность < порога отката (по умолчанию 60 %) | −1 | `down` |
| Точность < 40 % | **−2** | `drop` |
| Иначе | 0 | `stay` |

«Быстро» — медиана ответа не больше `fastMs` игры, или на 20 % быстрее своего
прошлого темпа на этом уровне, или (на новом уровне) не медленнее, чем на уровнях
ниже. «Очень медленно» — в 1,5 раза медленнее своего темпа или в 2,5 раза
медленнее `fastMs`. Меньше трёх ответов — скорость не учитывается.

Пороги у каждой игры свои и передаются в `rules`; уровень по-прежнему хранит
сама игра.

## Как подключить игру

```ts
import { levelLog, levelNote, nextLevelSmart, statsFromRun } from '../../core/smartLevel';

// в конце игры, ДО run.end():
const d = nextLevelSmart('my-game-id', this.level, statsFromRun(this.run, right, total), {
  maxLevel: MAX_LEVEL, up: 0.9, down: 0.6, // fastMs: 2500 — если у игры понятная «быстрая» скорость
});
saveMyLevel(d.level);
this.run?.end({ completed: true, stars, score: right, total, ...levelLog(d) });
// на экране итогов: levelNote(this.level, d) → «Перескок! Уровень 3 → 5» / «Новый уровень: 4» / «Потренируемся на уровне 2»
```

- `right/total` — как игра считает сама (вторые попытки, проверки и т. п.).
- Время ответов и серия первых попыток берутся из `run.answer()` (`run.results()`),
  поэтому в каждом ответе важно передавать `correct`, а для ответов с долгим
  объяснением — честный `ms`.
- Если уровень у игры — не число от 1 до N, а лестница ступеней (якорь), то
  `level` = номер ступени, `maxLevel` = число ступеней.

## Где уже подключено

- «Наоборот, юнга!», «Камбуз», «Рваная карта», «Верфь», «Истории команды» — через `nextLevelSmart`.
- Путешествие (острова, переход, бочки/чайки/буи) — в `src/core/adaptivity.ts`:
  второй подряд безошибочный подъём уровня перескакивает ступеньку
  (`SkillState.momentum`), три показанных решения подряд — сразу уровень назад.

## Ещё не подключено (идут в других ветках)

- **Гонка** (`race`): в конце заезда передать в `nextLevelSmart('race', …)` число
  верных ответов на щитах со словами и бустере; `fastMs` ≈ время, за которое щит
  проезжает половину экрана. Новый уровень — сложность арифметики бустера.
- **Якорь** (`anchor`, PR #23, лестница до 20–100 с откатом): заменить свой
  `nextLevel(level, meanPae)` на `nextLevelSmart('anchor', step, { right: близких, total: целей }, { maxLevel: число ступеней, up: 0.9, down: 0.5 })`.
  Средняя ошибка PAE остаётся для звёзд; «близко» = PAE ниже порога ступени.
- **Новые логические игры**: подключать по шаблону выше с первого дня, id = id в реестре.
- **Змейка** и **Посылка** уровней пока не имеют (сложность растёт внутри игры
  и по маршруту), поэтому не трогались.
