# Синхронизация прогресса между устройствами

Игра хранит всё в браузере (IndexedDB и localStorage) и работает без интернета. Синхронизация
копирует прогресс и статистику между устройствами семьи: ноутбук, телефон, другой браузер.

## Как это устроено

- У семьи есть **код семьи** из 16 случайных букв и цифр. Он и есть ключ: без него данные не
  прочитать, списка семей на сервере нет.
- Каждое устройство хранит в облаке **свой** файл `<код>/<устройство>` и читает файлы остальных.
  Два устройства никогда не перезаписывают загрузку друг друга.
- Когда синхронизируется:
  - при запуске игры (ждёт до 4 секунд, без сети стартует сразу с тем, что есть);
  - через несколько секунд после конца каждой игры;
  - когда вкладку сворачивают (только отправка) и когда к ней возвращаются через минуту и больше;
  - когда появилась сеть;
  - по кнопке «Синхронизировать сейчас» в «Для родителей → Данные».
- Что передаётся: прогресс всех мини-игр и словарь английских слов (localStorage), профиль
  плавания, попытки плавания и журнал событий (последние 20 000). Файл сжимается (gzip).
- Как сводится:
  - прогресс игр и профиль плавания: **побеждает более поздняя запись** (каждая запись помечается
    временем, `src/core/sync/stamps.ts`);
  - журнал событий и попытки: **объединяются**, повторы отбрасываются, ничего не теряется;
  - значения, записанные до появления синхронизации, переносятся только туда, где их нет.
    Если ребёнок уже играл в одну игру на двух устройствах, после первой синхронизации остаётся
    прогресс каждого устройства, а со следующей игры дальше идёт общий.
- Ограничение: если играть на двух устройствах **одновременно без сети**, в одной и той же
  мини-игре останется прогресс того устройства, где играли позже. Статистика (журнал) сохранится
  с обоих.

Код: `src/core/sync/` (merge.ts чистая логика, sync.ts браузер), сервер `server/yandex-sync/index.js`,
тесты `tests/sync.test.ts`.

## Настройка сервера в Yandex Cloud (один раз, ~10 минут)

Всё в [консоли Yandex Cloud](https://console.yandex.cloud), в том же каталоге, где SpeechKit.

1. **Бакет.** Object Storage → «Создать бакет». Имя, например `yunga-sync-<что-угодно>`
   (имя должно быть уникальным во всём Yandex Cloud). Доступ на чтение объектов и списка объектов:
   **ограниченный**. Остальное по умолчанию.
2. **Сервисный аккаунт.** Identity and Access Management → Сервисные аккаунты → «Создать».
   Имя `yunga-sync`, роль `storage.editor`.
3. **Функция.** Cloud Functions → «Создать функцию», имя `yunga-sync`. Затем «Создать версию»:
   - среда выполнения **Node.js 22**, способ «Редактор кода»;
   - удалите пример и создайте файл `index.js`, вставьте в него содержимое
     [`server/yandex-sync/index.js`](../server/yandex-sync/index.js);
   - точка входа `index.handler`, таймаут 10 с, память 128 МБ;
   - сервисный аккаунт `yunga-sync`;
   - переменная окружения `BUCKET` = имя бакета из шага 1;
   - (по желанию) `ALLOW_ORIGIN` = `https://lamerios.github.io`, чтобы функцию могла вызывать
     только игра.
   - «Сохранить изменения».
4. На странице функции включите **«Публичная функция»** и скопируйте ссылку вида
   `https://functions.yandexcloud.net/d4e…`.
5. **Адрес в игру.** GitHub → репозиторий → Settings → Secrets and variables → Actions →
   вкладка **Variables** → «New repository variable»: имя `SYNC_URL`, значение — ссылка из шага 4.
   Затем Actions → «Deploy to GitHub Pages» → «Run workflow». Ссылка не секретная, данные защищает
   код семьи.
   До пересборки адрес можно вставить вручную: «Для родителей → Данные → Адрес сервера синхронизации».

Для одной семьи это укладывается в бесплатный уровень Cloud Functions и Object Storage
(несколько сотен вызовов в день и единицы мегабайт).

## Подключение устройств

1. На ноутбуке: «Для родителей» → «Данные» → «Включить на этом устройстве». Появится код семьи.
2. «Скопировать ссылку для другого устройства» и откройте эту ссылку на телефоне
   (или введите код там же, в «Данные → Подключить по коду»).
3. Готово: на телефоне появится прогресс ноутбука, дальше устройства обмениваются сами.

«Отключить на этом устройстве» оставляет прогресс в браузере и просто перестаёт его отправлять.
