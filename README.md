# Кругосветка юнги

Браузерная обучающая игра для ребёнка 5–6 лет: пираты, парусный спорт, кругосветка.
Чтение, счёт, алгоритмы и шахматы встроены в сюжет. Работает на ноутбуке и телефоне, без сервера.

Дизайн-документ (SDD v0.1): https://claude.ai/artifact/ATnHnTuYZb8hZHGv7a9Nra

## Запуск

```bash
npm ci
npm run dev     # http://localhost:5173
npm test        # тесты ядра (адаптивность, сессии, хранилище)
npm run build   # статическая сборка в dist/
```

## Устройство

- `src/core/` — правила игры без Phaser: адаптивная сложность, сборка острова, лимиты сессий, хранилище (IndexedDB), экспорт/импорт прогресса.
- `src/scenes/` — сцены Phaser: загрузка → гавань → карта → остров → ночь.
- `src/game-state.ts` — связка сцен с ядром.

## Озвучка

Все реплики лежат в `content/phrases.json`, ударение ставится `+` перед гласной (`зап+иска`). Фразы с числами режутся на кусочки: `{n}` — число в именительном падеже, `{n:gen}` — в родительном («до восьми»), `{t:text}` — текст записки. Слова записок берут ударения из словаря `stress` в том же файле.

`tools/tts.ts` генерирует mp3 через Yandex SpeechKit в `public/audio/` и пересинтезирует только новые или изменённые фразы:

```bash
npm run tts -- --dry-run                       # что будет сгенерировано, ключ не нужен
YANDEX_SPEECHKIT_API_KEY=… npm run tts         # сгенерировать
YANDEX_SPEECHKIT_API_KEY=… npm run tts -- --samples alena,filipp,ermil,jane   # послушать голоса → audio-samples/
```

Без ключа на компьютере: добавьте секрет `YANDEX_SPEECHKIT_API_KEY` в Settings → Secrets and variables → Actions — при каждом изменении фраз (или вручную: Actions → «Voice-over (SpeechKit)») mp3 сгенерируются и закоммитятся в ту же ветку. Если какого-то клипа нет, игра произносит фразу голосом браузера.

## Змейка: английские слова

Отдельная мини-игра вне плавания (кнопка «Змейка» в гавани или ссылка `…/game/#snake`). Голос называет английское слово, ребёнок ведёт змейку Шушу к нужной картинке: стрелки/WASD, свайп или тап по полю, кнопки на экране. Проиграть нельзя: поле замкнуто, неверная картинка называется по-английски и исчезает. Режимы: слова, числа (0–20 и десятки до 100; позже рядом ставится похожее на слух число, thirteen/thirty), всё вместе.

- Словарь: 123 картинки (фрукты, овощи, еда, животные, транспорт, дом, одежда, игрушки, природа, части тела), 10 цветов и 29 чисел. В игре 10 слов: не больше 4 новых (простые раньше), затем те, что ещё учатся, затем повторение выученных. Слово выучено после 3 верных попаданий с первого раза (статистика в localStorage).
- Статистика для родителей: «Для родителей» → «Английские слова». По каждому слову: сколько раз спрашивали, сколько найдено с первой попытки, ошибки и с чем путает; трудные слова сверху. Данные в localStorage (`src/core/wordStats.ts`, ключ `english-words`); другие игры пишут туда же через `recordWord(id, wrongPicks)`.
- Слова и картинки: `src/games/snake/logic.ts`, `public/snake/*.webp` (Fluent Emoji 3D, MIT); цвета и числа рисуются в коде.
- Озвучка: раздел `english` в `content/phrases.json`, клипы `en.<id>` делает открытая нейросеть Kokoro (голос `af_heart`) через `tools/kokoro_tts.py` в том же workflow.

## Кругосветная посылка: транспорт и английский

Отдельная мини-игра вне плавания (кнопка «Посылка» в гавани или ссылка `…/game/#parcel`). Попугай Румб получает таинственную посылку «доставить на другой конец света», за ней охотится сорока Трещотка. Шесть этапов по кругу: море, пустыня Сахара, Гималаи, рельсы Японии, Тихий океан, Аляска. На каждом диспетчер по-английски говорит, на чём ехать («Take the camel!»), ребёнок выбирает картинку; неверный транспорт тонет, вязнет или отскакивает, называется по-английски, Румб подсказывает по-русски. Потом погрузка: «Load three boxes!», дальше с цветом («Load two red boxes!»), проверка по кнопке «Вперёд!». В пути сорока пытается утащить посылку, тап её прогоняет. В финале посылка возвращается в гавань (Земля круглая) и открывается. Прогресс по этапам хранится в localStorage.

- Правила и задания: `src/games/parcel/logic.ts`, сцена `src/games/parcel/ParcelScene.ts`, картинки `public/parcel/*.webp` (Fluent Emoji 3D, MIT).
- Английские реплики (`englishLines()` в logic.ts) лежат в `english.words` файла `content/phrases.json`, клипы делает Kokoro; русские реплики `rumb.parcel.*` и `magpie.*` (новый голос сороки в `speakers`).

## Статус

Этап 1 — каркас. Этап 2 — «Записка в бутылке» (чтение, 5 уровней) и «Загрузка трюма» (счёт, 6 уровней) с лесенкой подсказок; озвучка пока синтезом браузера. Этап 3 — «Прокладка курса» (алгоритмы, 5 уровней, переход между островами) и «Шахматный форт» (5 уровней, позиции проверяются chess.js). Экшн-этапы в пути (`src/games/action/`): после прокладки курса каждый выход приносит одну «ловилку» — «Бочки за бортом» (собрать ровно N, десятичная рамка), «Чайки с буквами» (собрать слово по звукам, клеточки Эльконина) или «Буи-узоры» (продолжить закономерность); остров своего навыка такую не получает. За выход ребёнок читает не больше одного текста: следующие задания на чтение превращаются в «Чаек». Верфь и журнал — этап 4.
