# Кругосветка юнги

Браузерная обучающая игра для ребёнка 5–6 лет: пираты, парусный спорт, кругосветка.
Чтение, счёт, алгоритмы и шахматы встроены в сюжет. Работает на ноутбуке и телефоне, без сервера.

Дизайн-документ (SDD v0.1): https://claude.ai/artifact/ATnHnTuYZb8hZHGv7a9Nra

## Запуск

```bash
npm ci
npm run dev     # http://localhost:5173
npm test        # тесты ядра (адаптивность, сессии, хранилище)
npm run build   # статическая сборка в dist/
```

## Главное меню

Первый экран: гавань с командой и карточка для каждой игры (Кругосветка, Змейка, Посылка, Гонка…). Первое нажатие «Играть!» включает звук на телефоне. Игры перечислены в `src/games/registry.ts`: новая игра появляется в меню одной записью, ссылка `…/game/#<id>` открывает её сразу. «Домой» в любой мини-игре возвращает в меню; Кругосветка открывается карточкой и возвращается кнопкой «Меню».

## Панель родителя и журнал событий

«Для родителей» в меню (решить пример на умножение) открывает панель: время по дням, игры, процент ответов с первого раза, самые трудные слова и что ребёнок с чем путает, сигналы («слишком трудно», «часто бросает», «реплика без клипа»), журнал событий, выгрузка JSON/CSV/отчёт. Данные хранятся только в браузере. Мини-игры пишут события через `src/core/analytics.ts` (`startRun` → `ask` / `answer` / `event` → `end`), отчёт строит `src/core/analyticsReport.ts`. Отчёт по выгрузке: `npm run analyze -- yunga-2026-11-20.json`. Словарь событий и пороги сигналов: [docs/analytics.md](docs/analytics.md).

## Устройство

- `src/core/` — правила игры без Phaser: адаптивная сложность, сборка острова, лимиты сессий, хранилище (IndexedDB), экспорт/импорт прогресса.
- `src/scenes/` — сцены Phaser: загрузка → гавань → карта → остров → ночь.
- `src/game-state.ts` — связка сцен с ядром.

## Озвучка

Все реплики лежат в `content/phrases.json`, ударение ставится `+` перед гласной (`зап+иска`). Фразы с числами режутся на кусочки: `{n}` — число в именительном падеже, `{n:gen}` — в родительном («до восьми»), `{t:text}` — текст записки. Слова записок берут ударения из словаря `stress` в том же файле.

`tools/tts.ts` генерирует mp3 через Yandex SpeechKit в `public/audio/` и пересинтезирует только новые или изменённые фразы:

```bash
npm run tts -- --dry-run                       # что будет сгенерировано, ключ не нужен
YANDEX_SPEECHKIT_API_KEY=… npm run tts         # сгенерировать
YANDEX_SPEECHKIT_API_KEY=… npm run tts -- --samples alena,filipp,ermil,jane   # послушать голоса → audio-samples/
```

Без ключа на компьютере: добавьте секрет `YANDEX_SPEECHKIT_API_KEY` в Settings → Secrets and variables → Actions — при каждом изменении фраз (или вручную: Actions → «Voice-over (SpeechKit)») mp3 сгенерируются и закоммитятся в ту же ветку. Если какого-то клипа нет, игра произносит фразу голосом браузера.

## Змейка: английские слова

Отдельная мини-игра вне плавания (кнопка «Змейка» в гавани или ссылка `…/game/#snake`). Голос называет английское слово, ребёнок ведёт змейку Шушу к нужной картинке: стрелки/WASD, свайп или тап по полю, кнопки на экране. Проиграть нельзя: поле замкнуто, неверная картинка называется по-английски и исчезает. Режимы: слова, числа (0–20 и десятки до 100; позже рядом ставится похожее на слух число, thirteen/thirty), всё вместе.

- Словарь: 123 картинки (фрукты, овощи, еда, животные, транспорт, дом, одежда, игрушки, природа, части тела), 10 цветов и 29 чисел. В игре 10 слов: не больше 4 новых (простые раньше), затем те, что ещё учатся, затем повторение выученных. Слово выучено после 3 верных попаданий с первого раза (статистика в localStorage).
- Статистика для родителей: «Для родителей» → «Английские слова». По каждому слову: сколько раз спрашивали, сколько найдено с первой попытки, ошибки и с чем путает; трудные слова сверху. Данные в localStorage (`src/core/wordStats.ts`, ключ `english-words`); другие игры пишут туда же через `recordWord(id, wrongPicks)`.
- Слова и картинки: `src/games/snake/logic.ts`, `public/snake/*.webp` (Fluent Emoji 3D, MIT); цвета и числа рисуются в коде.
- Озвучка: раздел `english` в `content/phrases.json`, клипы `en.<id>` делает открытая нейросеть Kokoro (голос `af_heart`) через `tools/kokoro_tts.py` в том же workflow.

## Посылка: штурман маршрута (транспорт, планирование, английский)

Отдельная мини-игра (`…/game/#parcel`). Диспетчер по-английски называет зверя («Take the parcel to the lion!»), ребёнок находит его на карте. Потом он раскладывает транспорт из гаража (по одной фишке на дорогу) по участкам карты: море, дорога, рельсы, пустыня, снег, горы, воздушный путь между аэропортами. Маршрут должен целиком дойти от гавани до зверя. По кнопке «Поехали!» план проигрывается и останавливается там, где он ломается: лодка застревает в песке, а на месте, где дорога обрывается, посылка встаёт. Начиная со 2-го уровня кратчайший путь становится ловушкой: гараж его не покрывает, и нужно искать обход. С 3-го уровня сорока Трещотка может утащить лишнюю машинку. Кнопка «?» подсказывает следующий участок, но тогда доставка не засчитывается.

- 8 уровней (`levelSpec` в `src/games/parcel/route.ts`): размер карты, ловушка, горы и вертолёт, самолёт между аэропортами, число лишних фишек и зверей-приманок. Уровень выбирает общий модуль `core/smartLevel` по 4 доставкам за игру. Верной считается доставка, у которой первый же план сработал без подсказки.
- Генератор проверяет каждую карту перебором маршрутов (`workingRoutes`), так что карта всегда решаема.
- Английский: `to.<зверь>`, названия транспорта и зверей, `thanks`, `notme` лежат в `english.words`. Зверь записывается в общий словарь слов. Русские реплики: `rumb.route.*` и `magpie.steal`.

## Гонка слов: машины и английский

Отдельная мини-игра вне плавания (кнопка «Гонка» в гавани или ссылка `…/game/#race`). Енот Болтик, механик гоночной команды, встречает в меню: машина на подиуме, гараж, монеты, нитро и пять трасс. Вид из-за багажника, псевдо-3D: город с домами, фонарями и деревьями проносится мимо, дорога плавно петляет, скорость видна по разметке, домам и спидометру. Голос говорит английское слово, на полосах стоят щиты с картинкой и словом: нужно перестроиться и въехать в правильный. Стрелки влево/вправо — полоса, вперёд/назад — газ и тормоз (на телефоне кнопки на экране и свайпы). Когда щиты близко, машина сама сбрасывает скорость на четверть. Не то слово — машина останавливается, Болтик разбирает оба слова, потом «Поехали!»; конус — авария на ходу. 12 слов за гонку: 10 правильных — три звезды, 7 — две, 5 — одна. Звезда открывает следующую трассу:

1. «Утренний город» — 3 полосы, простые слова.
2. «Шоссе на закате» — 3 полосы, все слова Змейки, похожие картинки рядом, конусы.
3. «Ночные огни» — 4 полосы, слова, цвета и числа до 20, конусы.
4. «Над морем» — самолёт: 3 полосы и 2 высоты (стрелки вверх/вниз или кнопки «выше/ниже»), карточки висят на воздушных шариках, внизу море с островами и кораблями. Пролетел мимо всех карточек — то же слово ещё раз.
5. «Над облаками» — самолёт, похожие картинки, грозовые тучи вместо конусов.

Новые слова приходят по три за гонку, остальное — уже встречавшиеся и те, на которых ребёнок ошибался.

**Числовая прямая и бустеры.** Каждое правильное слово двигает машину на шаг по прямой 0–50 вверху экрана. После 4-го, 8-го и 11-го слова бустер, задача растёт от трассы к трассе: выбрать больший бустер; два бустера сразу (сложение); какая пара бустеров даёт больше; лужа масла (для самолёта встречный ветер) откатывает назад (вычитание). Потом ребёнок угадывает, куда приедем, и машина едет по шагам, голос считает по-английски вперёд или назад. Неверный ответ — бустер сгорает: машина остаётся на месте, Болтик называет правильный ответ, а гонка уже не считается «без ошибок».

**Твоя трасса.** Умный уровень (`src/core/smartLevel.ts`) после каждой гонки решает, какая трасса — «твоя»: слова, ответы бустера и конусы считаются вместе, отличная гонка поднимает на трассу или две выше, слабая опускает. Трассы ниже своей — тренировка: монеты пополам, машин нет, уровень не меняется. Так лёгкую трассу не «пофармить».

**Гараж.** Гонка без единой ошибки (все 12 слов, ни одного конуса) на своей трассе или труднее дарит следующую машину, а полёт без ошибок на самолётной трассе — следующий самолёт (8 самолётов, вкладка «Самолёты» в гараже), всего 12 (полиция, такси, с пламенем, со звёздами, золотая…). За каждое правильное слово монета, за гонку без ошибок ещё 5. В гараже можно купить нитро (не больше трёх): ребёнок отсчитывает монеты ровно по ценнику (3–9), голос считает по-английски. В гонке кнопка с огнём (или N) на 3 секунды разгоняет в полтора раза, у щитов нитро гаснет.

**Пит-стоп.** После трёх аварий: 10 приседаний («Присел!»), 10 отжиманий («Отжался!»), голос считает по-английски, потом лабиринт: найти потерянную деталь и отвезти её в гараж (стрелки, кнопки, свайп или тап по соседней клетке; каждый шаг голос называет: Left! Up!). Лабиринт растёт с трассой (5×4, 6×5, 7×5).

- Правила: `src/games/race/logic.ts`, сцена `src/games/race/RaceScene.ts`, гараж `garage.ts`, пит-стоп и лабиринт `pitstop.ts`, рисунки машин, самолёта и города `art.ts` (свои SVG). Картинки слов берутся из Змейки, поэтому новые слова Змейки сами попадают в гонку.
- Реплики Болтика `raccoon.race.*`, английские `car.*` и `race.*` в `content/phrases.json`. Прогресс (звёзды, машины, монеты, нитро, слова с ошибками и встречавшиеся) в localStorage `race-progress`.

## Телефон и полный экран

На телефоне первый тап разворачивает игру на весь экран (кнопка ⛶ внизу, если вышли), Android поворачивает картинку боком. Если телефон держат вертикально, игра просит повернуть его. На iPhone Safari полноэкранного режима нет: «Поделиться → На экран „Домой“», и игра открывается с ярлыка без панелей браузера (`public/manifest.webmanifest`, `src/core/fullscreen.ts`).

## Статус

Этап 1 — каркас. Этап 2 — «Записка в бутылке» (чтение, 5 уровней) и «Загрузка трюма» (счёт, 6 уровней) с лесенкой подсказок; озвучка пока синтезом браузера. Этап 3 — «Прокладка курса» (алгоритмы, 5 уровней, переход между островами) и «Шахматный форт» (5 уровней, позиции проверяются chess.js). Экшн-этапы в пути (`src/games/action/`): после прокладки курса каждый выход приносит одну «ловилку» — «Бочки за бортом» (собрать ровно N, десятичная рамка), «Чайки с буквами» (собрать слово по звукам, клеточки Эльконина) или «Буи-узоры» (продолжить закономерность); остров своего навыка такую не получает. За выход ребёнок читает не больше одного текста: следующие задания на чтение превращаются в «Чаек». Верфь и журнал — этап 4.
